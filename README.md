# JUST ONE BOSS - 회피형 아케이드 게임

보스의 공격 패턴을 피하며 생존하는 회피형 아케이드 게임입니다.
원작 구조를 분석해 공격 패턴과 난이도 구성을 재구성한 변형 구현입니다.

- GitHub: https://github.com/kimseoyeon6465/UnityGameLab/tree/JustOneBoss
- 포트폴리오: https://github.com/kimseoyeon6465/Portfolio

|---|---|

| 인원 | 1명 (개인 프로젝트) |

## 핵심 구현

- **역할 단위 분리:** 보드, 타일, 패턴, 경고 시스템을 역할별로 나누고 `BoardManager` 중심으로 실행 순서를 통합했습니다.
- **페이즈 시스템:** 보스 공격 패턴을 JSON 데이터로 정의하고, `PhaseController`가 페이즈 전환과 패턴 실행을 담당합니다.
- **플레이어 컨트롤:** 입력 해석(`InputHandler`)과 이동, 애니메이션 로직을 분리했습니다.
- **초기화 순서 관리:** `GameInitializer`로 Awake/Start 실행 순서에 의존하지 않고 시스템 초기화 순서를 명시적으로 관리했습니다.

## 개선한 점

| 문제 상황 | 해결 |
|---|---|
| 패턴 실행 순서와 경고 타이밍이 섞여 디버깅이 어려움 | `BoardManager` 중심의 실행 순서 관리로 정리 |
| 씬을 다시 시작할 때 일부 시스템의 초기화가 빠짐 | 초기화 순서를 정의하는 Initializer 구조로 해결 |
